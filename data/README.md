# Dataset notes

This repository includes the supplied case-study CSV so the analysis can be reproduced.
Non-predictive identifiers have been removed from the distributed copy. The values
used for analysis are retained; missing-value imputation and fixed validity checks
occur in the Python pipeline and are recorded in the evaluation audit.

This is an adapted historical case-study dataset, not a live production feed.
The original upstream source and an open-data licence were not supplied with the CSV.
No new licence or ownership claim is asserted over the underlying data. Further
redistribution should respect the original data owner's terms.
